## Installing via HACS

Add the repo URL under HACS → ⋮ → Custom repositories (type: Integration or Dashboard), then install.

## Adding a project

Add a row to the right table above. The `.gitignore` ignores all sub-folders, so project repos can be cloned beside this README without being tracked here.
